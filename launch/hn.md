Show HN: Formwork – Sketch an interface out of plain characters

Every wireframe tool exports an image nobody can edit in a pull request or a chat. Formwork draws the wireframe out of characters. Pick a component, place it on the grid, copy. It pastes into a README, an issue, a commit message, a Slack thread, and stays editable everywhere. Listed on the App Store as Wiretext. Web at wiretext.heyitsmejosh.com, source on GitHub.
