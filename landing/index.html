Blockframe

Sketch an interface out of characters. Pick a component, click to place it on the grid, and export the whole thing as plain text you can paste into a README, an issue, or a commit message.

Built for quick, throwaway layouts

    

      
23 ready-made components
Buttons, inputs, selects, tables, modals, navbars, tabs, breadcrumbs and more — placed as characters, not pixels.

      
Click to place
Hover to preview exactly where a component lands on the 100×50 grid, then click to commit it.

      
Export as plain text
Copy to the clipboard or save a .txt. It reads correctly anywhere a monospace font does.

      
Undo and redo
Fifty steps of history, so experimenting costs you nothing.

      
Native on iOS and macOS
A real SwiftUI app on iPhone, iPad and Mac, not a wrapped web page — same grid, same components as the web version.

      
Free and open source
No ads, no purchases, no accounts. The source is on GitHub.
